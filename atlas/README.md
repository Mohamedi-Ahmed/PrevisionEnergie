# Atlas metadata pack

Ce dossier contient une préparation légère des éléments E6 pour Apache Atlas :
- glossaire métier ;
- entités à cataloguer ;
- processus de lignage.

L’objectif n’est pas de fournir une plateforme Atlas complète dans le dépôt, mais une base d’import ou de déclaration pour démontrer :
- la couverture sémantique ;
- la couverture des modèles ;
- le lignage bout en bout ;
- les dépendances entre sources, Silver, Gold et API.
